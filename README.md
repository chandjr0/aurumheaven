# Aurum Haven

Production website for **Aurum Haven** — a Dubai real estate brokerage providing advisory across residential, commercial, investment, off-plan, secondary-market and leasing decisions.

**Site:** [aurumhavenrealestate.com](https://www.aurumhavenrealestate.com/)

## Development

Requires Node.js and a package manager (npm, bun, or pnpm).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run build` | Production build |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
| `npm run format` | Format with Prettier |
